# Security Policy

## Supported Versions

Only the latest release running on the `main` branch receives active security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please follow responsible disclosure guidelines. **Do not create public GitHub issues for security vulnerabilities.**

### Preferred Reporting Method

Please report security issues privately using [GitHub Private Vulnerability Reporting](https://github.com/vvojtisek/workout-logger/security/advisories/new).

### What to Include

To help resolve the issue quickly, please provide:
* Description of the vulnerability and potential impact.
* Clear step-by-step reproduction steps or a minimal Proof of Concept (PoC).
* Affected component (e.g., FastAPI endpoint, authentication middleware, Helm/k3s configuration).

### Response SLA

* **Initial Acknowledgement:** Within 48 hours.
* **Assessment & Status Update:** Within 5 business days.
* **Fix & Release:** Critical vulnerabilities will be patched on `main` and rolled out as soon as a fix is verified.
